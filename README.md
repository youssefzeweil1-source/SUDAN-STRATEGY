# السودان: استراتيجية — نسخة السيناريو الأولى

نسخة تأسيسية من لعبة استراتيجية تفاوضية عربية تعمل من الواجهة الثابتة، وتدعم كتالوجًا من Cloudflare D1 مع fallback محلي للعمل دون اتصال. تركّز اللعبة على مفاضلات الشرعية والاستقرار والخدمات داخل سيناريو خيالي.

## تنبيه المحتوى

الجهات والأرقام والتأثيرات الموجودة في `database/seed.sql` و`data/catalog.json` خيالية لأغراض اللعب والتعليم. لا تمثل أسماء حركات أو مؤسسات حقيقية، ولا خريطة سيطرة، ولا معلومات ميدانية أو عسكرية حالية.

## ما تم تنفيذه

تحتوي الواجهة العربية RTL على ملف السيناريو، والولايات السودانية الـ18، وبطاقات الجهات الخيالية الأربع، ومؤشرات الشرعية والاستقرار والخدمات، وثلاثة أحداث تفاوضية بثلاثة قرارات لكل حدث، وثلاثة أهداف، بالإضافة إلى الحفظ المحلي والتصدير والاستيراد.

تم تجهيز قاعدة Cloudflare D1 باسم `sudan-strategy-db`، مع Worker مستقل باسم `sudan-strategy-api`. واجهات Worker هي `/health` و`/api/catalog` و`/api/saves`، والواجهة مضبوطة حاليًا على العنوان العام للـ Worker داخل `js/config.js`. الحفظ السحابي مجهول الهوية ويستخدم معرف جلسة عشوائيًا؛ لا ترسل اللعبة اسمًا أو بريدًا أو بيانات شخصية.

## التشغيل المحلي

يفضّل تشغيل الملفات عبر خادم محلي حتى تعمل ملفات JSON وService Worker بصورة صحيحة:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. إذا رغبت في تشغيل اللعبة بدون Worker، اجعل `apiBase` فارغًا في `js/config.js` وستستخدم اللعبة `data/catalog.json` والحفظ المحلي فقط.

## ملفات البيانات والبنية

- `database/schema.sql`: مخطط جداول D1.
- `database/seed.sql`: السيناريو والبيانات الأولية.
- `cloudflare/worker.js`: API متصل بربط D1 باسم `DB`.
- `cloudflare/wrangler.toml`: إعداد Worker ومعرّف قاعدة البيانات.
- `data/catalog.json`: نسخة fallback مطابقة لبنية API.
- `js/app.js`: دورة اللعبة والاختيارات والحفظ والمزامنة.
- `js/config.js`: عنوان Worker العام القابل للتغيير.

## نشر Worker يدويًا

إذا احتجت إعادة النشر من بيئة تملك Wrangler، استخدم إعداد `cloudflare/wrangler.toml` بعد تسجيل الدخول إلى حساب Cloudflare:

```bash
cd cloudflare
npx wrangler d1 execute sudan-strategy-db --remote --file=../database/schema.sql
npx wrangler d1 execute sudan-strategy-db --remote --file=../database/seed.sql
npx wrangler deploy
```

لا تضع مفاتيح Cloudflare أو أي أسرار داخل ملفات الواجهة أو الريبو.

## النشر على GitHub Pages

يمكن نشر الجذر كصفحة ثابتة من فرع `main`. ستقرأ الصفحة الكتالوج من Worker المنشور، وتعود تلقائيًا إلى النسخة المحلية إذا تعذر الوصول إلى API. لا تحتاج GitHub Pages إلى معرفة بيانات اعتماد Cloudflare لأن الواجهة لا تحمل أي أسرار.

## طور الخريطة والجيوش

تتضمن النسخة الجديدة خريطة SVG تفاعلية مبنية من حدود الولايات، وجيوشًا خيالية تظهر كرايات على الخريطة. يستطيع اللاعب إنشاء جيش في ولاية، تجنيد مشاة ومدرعات ومدفعية ودعم جوي بموارد داخل اللعبة، نقل الجيش إلى ولاية مجاورة، أو بدء اشتباك سيناريوي محسوب بالقوة والمعنويات. تُحفظ الجيوش والموارد والحركة داخل حالة الحفظ المحلية، وتتم مزامنتها إلى D1 من خلال `/api/saves`.

حدود الولايات موجودة في `data/sudan-states.geojson`. تم استخدام ملف السودان الإداري المبسط من SimpleMaps، وهو مرخّص بموجب CC BY 4.0، مع الإبقاء على الخريطة للاستخدام الجغرافي العام داخل اللعبة وليس لتمثيل سيطرة عسكرية حالية. انظر [صفحة مصدر الخرائط](https://simplemaps.com/gis/country/sd) و[ملف GeoJSON المستخدم](https://simplemaps.com/static/svg/country/sd/admin1/sd.json).
