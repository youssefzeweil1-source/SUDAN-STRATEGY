# السودان: استراتيجية — المرحلة الأولى

نسخة تأسيسية لواجهة لعبة استراتيجية فردية تعمل دون اتصال بعد أول تحميل ناجح.

## الموجود حالياً
- واجهة عربية RTL.
- قائمة الولايات السودانية الـ18 (أسماء فقط، دون حدود جغرافية مرسومة).
- البحث عن ولاية واختيارها.
- حفظ محلي تلقائي باستخدام localStorage.
- تصدير واستيراد ملف حفظ JSON.
- Service Worker لتخزين ملفات الواجهة للعمل دون اتصال بعد تحميلها أول مرة.

## التشغيل محلياً
يفضل تشغيل المشروع عبر خادم محلي، وليس فتح index.html مباشرة، حتى تعمل ملفات JSON وService Worker بصورة صحيحة. يمكن استخدام إضافة Live Server في VS Code.

## النشر على GitHub Pages
1. افتح Settings ثم Pages.
2. اختر Deploy from a branch.
3. اختر main والمجلد /(root)، ثم Save.
4. افتح رابط GitHub Pages وانتظر تحميل الملفات أول مرة قبل تجربة وضع عدم الاتصال.

## ملاحظات مهمة
- Firebase غير مربوط بعد؛ سنضيفه بعد إنشاء مشروعك وتحديد مجموعات البيانات.
- لا تضع مفاتيح سرية أو صلاحيات إدارية في ملفات الواجهة.
- أسماء الولايات مبدئية. لم نرسم حدوداً جغرافية تقريبية حتى لا ندعي دقة غير موجودة.
- بيانات السيطرة والموارد والفصائل غير مضافة. يجب أن تأتي من مصادر موثوقة ومؤرخة، ثم تُستخدم كبيانات سيناريو وليست تحديثاً لحظياً.
- هذا نموذج واجهة ومحاكاة مدنية/اقتصادية، وليس أداة لتتبع قوات أو تخطيط عمليات حقيقية.
